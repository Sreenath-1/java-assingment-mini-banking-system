# Mini Banking System (Java)

This is a simple menu-driven banking system developed using Java.

## Features

- Create account
- Deposit money
- Withdraw money (with minimum balance check)
- Search account by account number
- Store and read account details from file

## Concepts Used

- Classes and Objects
- Constructors
- Access Modifiers
- ArrayList
- File Handling (FileReader, FileWriter, BufferedReader, BufferedWriter)
- Exception Handling

## How to Run

1. Compile the files:
   javac Account.java BankSystem.java

2. Run the program:
   java BankSystem
